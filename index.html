Things I've done

Here are a few cool things about me

ASL-to-Voice Converter

One of my most meaningful projects is the American Sign Language (ASL) to Voice Converter, designed to bridge communication gaps for the hearing-impaired. Using sensors and gesture recognition algorithms, the system interprets hand signs and converts them into audible speech in real time. This project challenged me to work with signal processing, machine learning, and embedded systems, and it highlights my passion for creating inclusive technology that has a tangible social impact.

Obstacle-Avoiding Autonomous Robot

I built an autonomous robot capable of navigating through environments while avoiding obstacles. Using ultrasonic sensors and real-time decision algorithms, the robot can move intelligently without human intervention. This project allowed me to apply robotic path planning, sensor integration, and programming logic in a tangible way, combining both mechanical design and software development.

IoT-Enabled Home Automation System

In another project, I developed an IoT-enabled home automation system that allows users to control appliances remotely via a smartphone app. The system uses wireless communication protocols to manage lighting, fans, and security sensors. This project helped me deepen my understanding of IoT networks, real-time data processing, and user interface design, while demonstrating how technology can simplify everyday life.

Robotic Arm Controlled with ESP32

I designed a robotic arm that can be controlled using an ESP32 microcontroller. It allows precise movements for tasks such as object manipulation and simple assembly operations. The project involved integrating sensors and servo motors to create a system capable of both manual and automated control. Through this project, I explored robot kinematics and the practical application of embedded systems in robotics.

Smart Air-Purifying Tiles

One of my most innovative projects is the Smart Air-Purifying Tiles, designed to improve indoor air quality using IoT technology. These tiles can detect pollutants in the air and automatically adjust purification levels to maintain a clean and healthy environment. They are not only functional but also integrate seamlessly into modern interiors, combining technology with aesthetics. This project reflects my ability to merge hardware and software to solve real-world problems.
